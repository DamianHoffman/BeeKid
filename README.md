# BeeKid – strona przedszkola (projekt koncepcyjny)

Statyczna strona fikcyjnego Przedszkola Publicznego BeeKid (Warszawa, Bemowo), wykonana jako projekt koncepcyjny przed docelową realizacją w WordPressie.

**Podgląd:** https://DamianHoffman.github.io/BeeKid/

## Co pokazuje projekt

- struktura menu jak w briefie: O przedszkolu, Jak pracujemy, Kuchnia, Dla rodziców, Porady, Rekrutacja, Kontakt
- nawigacja mobilna: zwijane menu i dolny pasek „Zadzwoń / Zapisz dziecko”
- kalendarz wydarzeń z eksportem do pliku .ics oraz wydruk planu tygodnia i jadłospisu
- jadłospis z oznaczeniem alergenów
- szablon artykułów w sekcji „Porady” (lead, ramka „W skrócie”, linkowanie wewnętrzne)
- podstawy SEO: tytuł, opis, Open Graph, dane strukturalne schema.org
- sekcja o terapii integracji sensorycznej (SI)

## Technologia

Czysty HTML, CSS i JavaScript, bez frameworków i bez procesu budowania. Logo, favicon i czcionki (Outfit, Nunito, licencja OFL) są wbudowane w `index.html`, więc strona działa także po otwarciu samego tego pliku.

## Uruchomienie

Otwórz `index.html` w przeglądarce albo włącz GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

Wszystkie dane (zespół, adres, ceny, opinie, terminy) są fikcyjne.
